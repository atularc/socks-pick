# Frameless map preview

The level map now uses a smooth teal gradient with no enclosing board, wooden rim, felt texture, corner decorations or room backdrop. The original dimensional level buttons, route, logo and actions remain.

The current-level marker is repositioned as the map scrolls and only shown where it fits without clipping or covering another level.

No new image assets or per-frame blur passes are used. This direction removes several map graphics.

Preview: ../Editor-Screen-Audit/frameless-map-preview.png

The Unity project contains this preview. Release exports are updated after visual verification.
